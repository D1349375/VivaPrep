# VivaPrep

面向大學個人申請的模擬面試與復盤原型。這一版先完成端到端前端體驗，所有面試事件與評語使用本機 mock，不呼叫 Gemini 或後端服務。面試場景使用 Three.js 即時繪製；考官是獨立的 3D 角色物件，可切換 1–3 人。

## 啟動

需要 Node.js 18 或更新版本。

```sh
npm run dev
```

瀏覽器開啟終端機顯示的本機網址（預設 `http://localhost:4173`）。

## 目前流程

校系情境 → 備審與主張確認 → 面試設定／考官陣容 → 設備檢查 → 模擬面試 → 逐題復盤與再練習。

面試場景包含房間、桌椅與坐在桌後的 3D 考官。程序建模角色是無模型素材時的保底版本；發問時會抬手說明，追問時會前傾並加強手勢，聆聽時會點頭，看備審時會低頭記錄。三種角色各自使用不同節奏和手勢。

產品主版本預計改用依原人物圖製作的高細節骨架 3D 角色。前端已可讀取 `public/assets/avatars/{technical,portfolio,logic}.glb`，並依 `Speaking`、`Listening`、`ReadingNotes`、`FollowUp` 等動畫片段切換；沒有模型檔時會繼續顯示程序版。原人物 PNG 只作為造型參考，無法直接轉成有身體、骨架和動作的 3D 模型。GLB 製作規格見 `public/assets/avatars/README.md`。

每場有全場倒數；教授提問後，若約 8 秒沒有聲音或文字輸入，原提問教授會自然接話或追問，不會自動跳題。語音情境可在本機使用麥克風音量偵測停頓；回答目前以文字輸入記錄，尚未接語音辨識。麥克風只在使用者主動連接後使用，離開面試或結束練習時會停止；影音與備審內容不會上傳或保存。

啟動前先安裝依賴：

```sh
npm install
```
