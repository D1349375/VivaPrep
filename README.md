# VivaPrep

面向大學個人申請的模擬面試與復盤原型。這一版先完成端到端前端體驗，所有面試事件與評語使用本機 mock，不呼叫 Gemini 或後端服務。面試場景使用 Three.js 即時繪製；考官是獨立的 3D 角色物件，可切換 1–3 人。

## 啟動

需要 Node.js 18 或更新版本。

```sh
npm run dev
```

瀏覽器開啟終端機顯示的本機網址（預設 `http://localhost:4173`）。

## 目前流程

校系情境 → 備審與主張確認 → 面試設定／考官陣容 → 設備檢查 → 模擬面試 → 逐題復盤與再練習。

面試場景包含房間、桌椅與坐在桌後的 3D 考官。三位角色各有外觀、服裝配色和個人動作；發問、聆聽、思考與閱讀備審時會播放不同的細微姿勢。可選三人完整評估團、雙人技術追問或一人引導對談，也能替換角色。

每場有全場倒數；教授提問後，若約 8 秒沒有聲音或文字輸入，原提問教授會自然接話或追問，不會自動跳題。語音情境可在本機使用麥克風音量偵測停頓；回答目前以文字輸入記錄，尚未接語音辨識。麥克風只在使用者主動連接後使用，離開面試或結束練習時會停止；影音與備審內容不會上傳或保存。

啟動前先安裝依賴：

```sh
npm install
```
