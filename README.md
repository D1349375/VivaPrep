# VivaPrep

面向大學個人申請的模擬面試與復盤原型。這一版先完成端到端前端體驗，所有面試事件與評語使用本機 mock，不呼叫 Gemini 或後端服務。

## 啟動

需要 Node.js 18 或更新版本。

```sh
npm run dev
```

瀏覽器開啟終端機顯示的本機網址（預設 `http://localhost:4173`）。

## 目前流程

校系情境 → 備審與主張確認 → 面試設定／考官陣容 → 設備檢查 → 模擬面試 → 逐題復盤與再練習。

考官是獨立透明 PNG 角色物件，面試室背景維持空場景。可選三人完整評估團、雙人技術追問或一人引導對談，也能在 1–3 人間調整並替換角色。

備審檔案不會上傳。設備檢查只在使用者主動按下按鈕後向瀏覽器請求攝影機／麥克風權限；離開檢查頁時會停止媒體串流。
